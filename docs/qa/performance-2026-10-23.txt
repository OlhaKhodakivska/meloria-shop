Changes and purpose
1. Re-encoded hero.webp with WebP quality 88 at the original 1896 x 520 size:
   695276 -> 78212 bytes (88.8% smaller).
   This uses lossy compression. A side-by-side image comparison showed no
   obvious visual degradation. The original hero.png remains unchanged.
2. Preloaded that image with high fetch priority in the initial homepage HTML.
   Vite resolves the asset URL; the SEO script removes the hint from generated
   non-home public pages. Existing CSS cropping, positioning and layout remain.
3. Replaced featured-product sorts with a maximum-price scan and Fisher–Yates
   shuffle. Both are linear in catalogue size. The first most expensive product
   remains first; the full remaining list supports later batches of 24.
4. Only sort new products when the New catalogue view is requested.
